# 🛒 Kurumsal E-Ticaret Platformu

Bu proje, modern yazılım mimarileri ve güvenli ödeme sistemleri kullanılarak geliştirilmiş, ölçeklenebilir bir e-ticaret çözümüdür.

## 🛠 Teknik Mimari ve Özellikler
* **Katmanlı Mimari (N-Tier Architecture):** Proje; DataAccess, Entity, Business ve UI katmanlarından oluşarak sürdürülebilirlik sağlar.
* **Repository Pattern:** Veri erişim mantığı soyutlanarak kodun test edilebilirliği artırılmıştır.
* **Fluent API:** Veritabanı modellemeleri ve kısıtlamaları (constraints) kod tarafında yönetilmiştir.
* **Iyzico Entegrasyonu:** Güvenli ödeme işlemleri için Iyzico API entegrasyonu tamamlanmıştır.

## 🚀 Teknolojiler
* .NET Core / MVC
* Entity Framework Core
* MS SQL Server
* Bootstrap & JavaScript
